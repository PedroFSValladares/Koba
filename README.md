# Koba
---
Koba é meu projeto pessoal no qual mais tenho orgulho e mais coloco empenho, tendo passado por diversas versões, padrões de projeto, tentativas, refatorações. Como sendo um projeto de muitos anos me serviu de muitos aprendizado do que fazer (e do que não fazer também) para manter um projeto manutenível e robusto. 

Como ultimo motivador, tive minha experiência recente como desenvolvedor treinee backend, depois de aprender na prática sobre divisão de responsabilidades, arquitetura em camadas e ver em ação um sistema conectado e funcionando numa arquitetura API LED. Pensei: porque não tentar dar vida a esse bot mais uma vez?
